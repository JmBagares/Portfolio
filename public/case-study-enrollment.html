1. Project Overview

The CvSU Enrollment System is a team project that provides students with a structured frontend for entering enrollment information and sending it to the application backend.

2. Problem and Objectives

The frontend needed to make a multi-step, form-heavy process understandable across screen sizes while exchanging data reliably with backend endpoints.

3. My Role and Contributions

I worked as the front-end developer. I built the responsive React interface, implemented client-side form validation and feedback, connected requests with Axios, and coordinated request and response behavior with the backend developers. I do not claim the team’s backend work as my own.

4. Technology Stack

  • React and JavaScript: screen and form behavior.
  • Bootstrap and CSS: responsive layout and interface styling.
  • Axios: requests between the frontend and backend API.

5. Key Features

  • Responsive enrollment screens for desktop and smaller devices.
  • Form validation and visible input feedback before submission.
  • Axios integration for backend communication.

6. Technical Implementation

The interface separates presentation and form behavior into React components. Validation checks input before a request is sent, while Axios handles the frontend’s calls to the backend contract agreed with the rest of the team.

7. Challenges and Solutions

The central documented challenge was coordinating a frontend form flow with separately developed backend behavior. Clear request structures, validation before submission, and coordination with the backend developers reduced avoidable request errors.

8. Testing and Results

Project screenshots and source code are available for review. No formal test metrics or production deployment are documented in the portfolio source, so no result is overstated.

9. What I Learned

The project provided practical experience in frontend/backend coordination, form-state handling, responsive UI work, and debugging API communication in a team setting.
